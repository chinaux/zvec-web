## 语言 SDK

| SDK | 安装 | 代码仓库 | 预编译产物覆盖 |
| --- | --- | --- | --- |
| Python | `pip install zvec`（64 位，3.10–3.14） | [alibaba/zvec · `python/`](https://github.com/alibaba/zvec/tree/main/python) | manylinux x86_64 / ARM64、musllinux x86_64 / ARM64、macOS ARM64、Windows x64 |
| Node.js | `npm install @zvec/zvec` | [zvec-ai/zvec-node](https://github.com/zvec-ai/zvec-node) | Linux x86_64 / ARM64（glibc 与 musl）、macOS ARM64 / x64、Windows x64 |
| Go | `go get github.com/zvec-ai/zvec-go` | [zvec-ai/zvec-go](https://github.com/zvec-ai/zvec-go) | Linux x64 / ARM64、macOS ARM64、Windows x64 |
| Rust | `cargo add zvec-rust` | [zvec-ai/zvec-rust](https://github.com/zvec-ai/zvec-rust) | Linux x86_64 / ARM64、macOS ARM64、Windows x64 |
| Java | Maven Central `org.zvec:zvec-java` | [zvec-ai/zvec-java](https://github.com/zvec-ai/zvec-java) | Linux x86_64 / ARM64（glibc 2.27 及以上）、macOS ARM64、Windows x64 |
| Dart / Flutter | `flutter pub add zvec` | [zvec-ai/zvec-dart](https://github.com/zvec-ai/zvec-dart) | Android arm64-v8a、iOS arm64、macOS ARM64、Linux x64、Windows x64 |

## 支持的软硬件平台

| 平台 | 架构 | CI 验证 | 预编译产物 |
| --- | --- | --- | --- |
| Linux（glibc） | x86_64、ARM64 | 完整构建与测试，另有 Clang 编译器兼容矩阵 | ✅ |
| Linux（musl） | x86_64、ARM64 | 自 v0.7.0 起，覆盖 Alpine 等 musl 发行版 | ✅ |
| macOS | ARM64（Apple Silicon）、x86_64（Intel） | ARM64 在 macOS 15 与 macOS 26 双版本验证；x86_64 在 Intel runner 上构建并测试 | ✅ |
| Windows | x86_64 | Windows Server 2022 与 2025 | ✅ |
| Android | arm64-v8a | 在 x86_64 模拟器中实际运行单元测试 | ✅ |
| iOS | arm64 | 跑模拟器测试并产出真机构建 | ✅ |
| RISC-V | riscv64 | 每周在原生 riscv64 runner 上完整构建并运行单元测试 | ❌ |

*✅ = 提供预编译产物 · ❌ = 需源码构建。*

## 索引可用性矩阵

| 索引 | Linux x86_64 | Linux ARM64 | macOS ARM64 | Windows x86_64 | Android arm64 | iOS arm64 | RISC-V |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| [Flat](../concepts/vector-index/flat-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| [IVF](../concepts/vector-index/ivf-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| [HNSW](../concepts/vector-index/hnsw-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| [Vamana](../concepts/vector-index/diskann-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 稀疏向量（Flat / HNSW） | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| RaBitQ（[HNSW](../concepts/vector-index/hnsw-rabitq-index/) / [IVF](../concepts/vector-index/ivf-rabitq-index/)） | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ |
| [DiskANN](../concepts/vector-index/diskann-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ❌ |
| [INVERT](../concepts/inverted-index/)（标量倒排） | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| [FTS](../concepts/fts-index/)（全文检索） | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

*✅ = 该平台可用 · ❌ = 不支持。*

<Callout className="text-base" type="info">
  **RaBitQ** 依赖 AVX2 与 AVX-512，因此目前仅支持 Linux x86_64。
</Callout>
