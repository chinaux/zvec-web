## Language SDKs

All SDKs share one stable C API boundary — pick your language to see the install command and prebuilt platform coverage.

<Tabs items={['Python', 'Node.js', 'Go', 'Rust', 'Java', 'Dart / Flutter']}>

<Tab value="Python">

```bash
pip install zvec
```

- **Prebuilt coverage**: manylinux x86_64 / ARM64, musllinux x86_64 / ARM64, macOS ARM64, Windows x64
- **Requirements**: 64-bit Python 3.10–3.14
- **Repository**: [alibaba/zvec · `python/`](https://github.com/alibaba/zvec/tree/main/python)

</Tab>

<Tab value="Node.js">

```bash
npm install @zvec/zvec
```

- **Prebuilt coverage**: Linux x86_64 / ARM64 (glibc and musl), macOS ARM64 / x64, Windows x64
- **Repository**: [zvec-ai/zvec-node](https://github.com/zvec-ai/zvec-node)

</Tab>

<Tab value="Go">

```bash
go get github.com/zvec-ai/zvec-go
```

- **Prebuilt coverage**: Linux x64 / ARM64, macOS ARM64, Windows x64
- **Repository**: [zvec-ai/zvec-go](https://github.com/zvec-ai/zvec-go)

</Tab>

<Tab value="Rust">

```bash
cargo add zvec-rust
```

- **Prebuilt coverage**: Linux x86_64 / ARM64, macOS ARM64, Windows x64
- **Repository**: [zvec-ai/zvec-rust](https://github.com/zvec-ai/zvec-rust)

</Tab>

<Tab value="Java">

```xml
<dependency>
  <groupId>org.zvec</groupId>
  <artifactId>zvec-java</artifactId>
</dependency>
```

- **Prebuilt coverage**: Linux x86_64 / ARM64 (glibc 2.27 or newer), macOS ARM64, Windows x64
- **Repository**: [zvec-ai/zvec-java](https://github.com/zvec-ai/zvec-java)

</Tab>

<Tab value="Dart / Flutter">

```bash
flutter pub add zvec
```

- **Prebuilt coverage**: Android arm64-v8a, iOS arm64, macOS ARM64, Linux x64, Windows x64
- **Repository**: [zvec-ai/zvec-dart](https://github.com/zvec-ai/zvec-dart)

</Tab>

</Tabs>


## Supported Platforms

| Platform | Architectures | CI verification | Prebuilt artifacts |
| --- | --- | --- | --- |
| Linux (glibc) | x86_64, ARM64 | Full build and tests, plus a Clang compatibility matrix | ✅ |
| Linux (musl) | x86_64, ARM64 | Since v0.7.0 — covers Alpine and other musl distributions | ✅ |
| macOS | ARM64 (Apple Silicon), x86_64 (Intel) | ARM64 validated on macOS 15 and macOS 26; x86_64 built and tested on Intel runners | ✅ |
| Windows | x86_64 | Windows Server 2022 and 2025 | ✅ |
| Android | arm64-v8a | Unit tests actually run inside an x86_64 emulator | ✅ |
| iOS | arm64 | Simulator tests plus device builds | ✅ |
| RISC-V | riscv64 | Weekly full build and unit tests on native riscv64 runners | ❌ |

*✅ = prebuilt artifacts published · ❌ = build from source.*

## Index Availability

| Index | Linux x86_64 | Linux ARM64 | macOS ARM64 | Windows x86_64 | Android arm64 | iOS arm64 | RISC-V |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| [Flat](../concepts/vector-index/flat-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| [IVF](../concepts/vector-index/ivf-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| [HNSW](../concepts/vector-index/hnsw-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| [Vamana](../concepts/vector-index/diskann-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| Sparse vectors (Flat / HNSW) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| RaBitQ ([HNSW](../concepts/vector-index/hnsw-rabitq-index/) / [IVF](../concepts/vector-index/ivf-rabitq-index/)) | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ |
| [DiskANN](../concepts/vector-index/diskann-index/) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ❌ |
| [INVERT](../concepts/inverted-index/) (scalar) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| [FTS](../concepts/fts-index/) (full-text) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

*✅ = available on that platform · ❌ = not available.*

<Callout className="text-base" type="info">
  **RaBitQ** requires AVX2 and AVX-512, which is why it is limited to Linux x86_64 today.
</Callout>
